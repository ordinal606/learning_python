# Learning Python

A collection of small, finished Python projects created to practice
core programming fundamentals such as input handling, control flow,
loops, error handling, and basic program structure.

Each project is self-contained and can be run from the command line.

## Projects

- **Calculator**  
  Command-line calculator supporting basic arithmetic operations with
  input validation and error handling.

- **Number Guessing Game**  
  CLI game where the user guesses a randomly generated number between
  1 and 100, with feedback and attempt tracking.
