# Number Guessing Game

A simple command-line number guessing game written in Python.
The program randomly selects a number between 1 and 100, and the user
attempts to guess it with feedback after each attempt.

## Features

- Random number generation
- Input validation for integer guesses
- Feedback for high and low guesses
- Attempt counter
- Option to replay the game

## How to Run

From the project directory:

```bash
python number_guessing_game.py
